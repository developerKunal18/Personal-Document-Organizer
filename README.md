# Personal Document Organizer

A simple Python command-line application to organize personal document
details such as certificates, bills, agreements, and identity documents.

## Features

- Add document details
- View all saved documents
- Search documents by title, category, or document number
- Filter documents by category
- Update document details
- Delete document records
- Track issue and expiry dates
- Store document information in JSON

## Technologies Used

- Python
- JSON
- File Handling
- Date and Time Handling
